隐私政策

生效日期：2026-10-19

1. 概述

xlsx-organizer 是一款离线工具。在设计上，你的电子表格数据不会离开你的设备。本政策说明软件如何处理数据，以及你通过邮件联系我们时会涉及哪些信息。

2. 软件在本机处理的数据

clean / files / merge / validate / report / compare / split / profile / unpivot / mask / enrich / reconcile 全部十二个功能（以及把它们串起来的配方与工作流，含内置月结作业）都在你的设备本地完成；软件不会将你的文件内容上传到任何服务器。运行历史、预设、配方、工作流等都保存在你本机的 ~/.xlsx-organizer/ 目录下，由你掌控，可随时删除。

软件完全免费，没有许可证或激活机制：它不读取、计算或存储任何机器标识符或硬件指纹，也不需要账号。

3. 唯一的联网路径：手动更新

仅当你主动运行 xlsx-organizer update check、在图形界面点击"检查更新"，或在发现新版本后点击应用内下载安装包时，软件才会发起更新相关请求。请求先发往 GitHub；仅当 GitHub 读不到（离线、被阻断、或应答不是可读的发行版信息）时，才会改向 Gitee 镜像重试。在一次请求内，GitHub 一旦答复就不会再联系 Gitee；而点击应用内下载会重新走一遍这个顺序，因此同样的先后关系再适用一次。这些请求：

  • 发送你的软件版本号（作为 User-Agent，如 xlsx-organizer/0.10.0）——检查更新与应用内下载时都会发送；
  • 应用内下载时请求该版本的安装包和 SHA256SUMS.txt，并在本机校验后才允许安装。涉及的主机：GitHub 侧为 api.github.com 与 github.com，安装包可能重定向到 *.githubusercontent.com；Gitee 侧为 gitee.com，附件可能重定向到 *.gitee.com；
  • 与任何网络请求一样，被请求到的那一方（GitHub 或 Gitee，含上述重定向目标）会看到你的 IP 地址；
  • 不发送你的任何文件内容、文件名或个人信息。

软件没有任何自动或后台联网、没有遥测、没有使用统计、没有广告或第三方跟踪。

往来邮件保留至处理你的问题所需的期限。你可通过联系邮箱要求查询、更正或删除这些信息。

Privacy Policy

Effective date: 2026-10-19

1. Overview

xlsx-organizer is an offline tool. By design, your spreadsheet data never leaves your device. This policy explains how the software handles data and what information is involved when you email us.

2. Data the software processes locally

The clean / files / merge / validate / report / compare / split / profile / unpivot / mask / enrich / reconcile features — all twelve of them, plus the recipes and workflows that chain them (including the built-in month-close job) — run locally on your device; the software does not upload your file contents to any server. Run history, presets, recipes, and workflows are stored under ~/.xlsx-organizer/ on your own machine, under your control, and can be deleted at any time.

The software is entirely free and has no license or activation mechanism: it does not read, compute, or store any machine identifier or hardware fingerprint, and it needs no account.

3. The only network path: manual updates

Only when you explicitly run xlsx-organizer update check, click "Check for updates" in the GUI, or choose the in-app download after a newer release is found does the software make update-related requests. They go to GitHub first; only if GitHub cannot be read (offline, blocked, or a reply that is not a readable release feed) are they retried against the Gitee mirror. Within one request, once GitHub answers Gitee is not contacted; starting an in-app download re-checks the feeds first, so the same order applies again. Those requests:

  • send your software version as a User-Agent (e.g. xlsx-organizer/0.10.0) — on the update check and on the in-app download alike;
  • request that release's installer and SHA256SUMS.txt when you download the installer in app, which is verified locally before installation is offered. The hosts involved: on the GitHub side api.github.com and github.com, with the installer possibly redirected to *.githubusercontent.com; on the Gitee side gitee.com, with the attachment possibly redirected to *.gitee.com;
  • like any network request, let whichever destination is contacted (GitHub or Gitee, including the redirect targets above) see your IP address;
  • does not send any of your file contents, file names, or personal information.

There is no automatic or background networking, no telemetry, no usage analytics, and no ads or third-party tracking.

4. When you email us

Downloading and using the software requires no personal information. Only when you choose to email us (for example for support or to report a problem) do we receive your email address and whatever you choose to include in the message (such as a report or log). It is used solely to reply to and resolve your request; we do not sell it or use it for unrelated purposes.

5. Retention & your rights

Correspondence is kept for as long as needed to handle your request. You may request access to, correction of, or deletion of it via the contact email.

6. This website

This website is a static site. It sets no tracking cookies and embeds no third-party analytics or fonts. Your language preference is stored only in your browser's localStorage, on your own device.

7. Contact

For privacy matters, contact deanymrq@gmail.com.
